## BREAK-EVEN ANALYSIS

### Key Metrics
- **Cost Per Sale = Total Ad Spend ÷ Number of Sales**
- **ROAS (Return on Ad Spend) = Revenue ÷ Ad Spend**
- **Target ROAS: 1.5x to 2.5x** (first month), then optimize

### Example Scenario
| Metric | Value |
|--------|-------|
| Daily Ad Spend | ₹2,000 |
| Monthly Ad Spend | ₹60,000 |
| CPC | ₹10 |
| Daily Clicks | 200 |
| Conversion Rate | 2.5% |
| Daily Sales | 5 |
| Revenue per Sale (with funnel) | ₹508 (avg) |
| Daily Revenue | ₹2,540 |
| Monthly Revenue | ₹76,200 |
| **ROAS** | **1.27x** |
| **After adding backend** | **2x-3x** |

### The Reality
- Front-end = break-even or tiny margin (~20% max after ads + taxes)
- **You become profitable in the BACKEND**
- Backend (₹4,497+) is where the real money is
- 100 front-end buyers → some % convert to backend → THAT is your profit

## SCALING MILESTONES

| Stage | Daily Ad Spend | Expected Daily Revenue | Monthly Revenue |
|-------|---------------|----------------------|-----------------|
| Test | ₹200 | ₹400-500 | ₹12,000-15,000 |
| Validate | ₹500 | ₹1,000-1,250 | ₹30,000-37,500 |
| Early Scale | ₹1,000 | ₹2,000-2,500 | ₹60,000-75,000 |
| Scale | ₹2,000 | ₹4,000-5,000 | ₹1.2-1.5 lakh |
| Aggressive | ₹5,000+ | ₹10,000+ | ₹3 lakh+ |

### Rules
1. Never jump stages — go ₹200 → ₹400 → ₹500 → ₹600
2. If account exhausted mid-day → PAUSE
3. Meta needs 7-14 days to learn your audience
4. Don't go aggressive early — TEST first
5. 48-hour creative test before scaling
6. 2x ROAS at ₹2,000/day = ₹1.2 lakh/month (the main use case)
