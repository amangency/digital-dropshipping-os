# Quick Reference: Value Stack Builder

## THE PROCESS (5 Moves)
1. **List** — Every distinct component (templates, recording, checklist = 3 items, not 1)
2. **Name** — Each item for the OUTCOME ("The 12-Point Rejection Filter" not "Module 3")
3. **Price** — Each item honestly (what would it cost if sold separately?)
4. **Total** — Add all up, then show your actual price
5. **Bonus** — Add ONE relevant bonus (must follow "next problem" principle)

## RULES
- Every number must be defensible
- No inflated numbers (destroys trust)
- Value must visibly exceed price BEFORE price is mentioned
- Listing creates weight — several items > one item (even if content is identical)
- Answers the silent question: "What do I ACTUALLY get?"

## BONUS EVALUATION
✅ Good Bonus:
- Solves the VERY NEXT problem after main outcome
- Consumable in minutes
- Feels like it could be sold separately
- Named for outcome ("30 Days, 30 Meals Plan")

❌ Bad Bonus:
- Unrelated to main promise
- Long thing = more work for buyer
- Obviously filler
- Named after format ("Bonus PDF #3")
- Too many bonuses = offer becomes unclear
