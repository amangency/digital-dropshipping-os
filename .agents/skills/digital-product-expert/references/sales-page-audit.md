# Quick Reference: Sales Page Audit Checklist

## THE 11 SECTIONS (Must be in this order)

### 1. HEADLINE
- [ ] States the big benefit in one sentence
- [ ] Example: "Get shortlisted in 7 days without rewriting your CV from scratch"
- [ ] Outcome-focused, not product-focused
- [ ] Would a stranger understand what they get?

### 2. SUBHEADLINE
- [ ] Names the specific audience
- [ ] Example: "For freelance designers in year two who keep underquoting"
- [ ] Filters in the right buyer, filters out the wrong one

### 3. THE PROBLEM
- [ ] Written in buyer's OWN words
- [ ] Specific enough they recognise themselves on the page
- [ ] Addresses the emotional pain, not just the logical problem
- [ ] "I'm tired of..." / "I've tried..." / "Nothing works because..."

### 4. THE TURN
- [ ] Acknowledges what they've already tried
- [ ] "You've tried this, you've tested this, no worries"
- [ ] Builds empathy before pitching
- [ ] Makes them feel understood, not sold to

### 5. THE REVEAL
- [ ] Introduces your solution/mechanism
- [ ] Has a NAME (branded method)
- [ ] Shows WHY this is different from what they've tried

### 6. WHAT'S INSIDE (The Stack)
- [ ] Every component listed separately
- [ ] Each named for OUTCOME, not format
- [ ] Each priced individually
- [ ] Total value shown prominently
- [ ] Actual price shown as dramatic contrast

### 7. PROOF
- [ ] Screenshots, testimonials, or your own story
- [ ] Real names/results where possible
- [ ] "If you have no proof, use your own result and say plainly you're early"
- [ ] Honest beats invented, every time

### 8. THE PRICE
- [ ] Total value shown first ("Worth ₹2,796")
- [ ] Then actual price ("Right now just ₹299")
- [ ] Framed as 90% discount
- [ ] Price appears AFTER value is fully built

### 9. RISK REVERSAL
- [ ] One clear line beside the buy button
- [ ] Unconditional (no conditions, no small print)
- [ ] "Use it for 7 days. If it doesn't work, reply to the receipt, refunded."
- [ ] Conditions DESTROY the effect

### 10. FAQ
- [ ] Addresses real objections
- [ ] Short, direct answers
- [ ] Covers: "Is this for me?", "How fast?", "What if it doesn't work?"
- [ ] Each FAQ is tracked as a pixel event

### 11. FINAL CTA
- [ ] ONE button
- [ ] ONE action
- [ ] Clear text ("Get Instant Access for ₹299")
- [ ] No other links on the page (every extra link = leak)

---

## PAGE-LEVEL CHECKS

### UX Requirements
- [ ] Mobile-first design
- [ ] Sticky CTA button after scrolling
- [ ] Exit intent popup
- [ ] Fast loading
- [ ] Clean, minimal (Linear/Notion/Stripe aesthetic)

### CRO Requirements
- [ ] Loss aversion messaging
- [ ] Social proof elements
- [ ] Authority signals
- [ ] Scarcity/urgency (authentic, not manufactured)

### Copywriting Rules
- [ ] Every feature converted to benefit
- [ ] Written in buyer's language
- [ ] Congruent with ad copy
- [ ] One page, one offer, one button
- [ ] "Could someone who's never heard of you read this and know exactly what they get?"

---

## COMMON MISTAKES
1. Price shown before value is built → feels expensive
2. Multiple offers on same page → confusion
3. Multiple buttons/links → leaks
4. Feature-heavy copy → no emotional connection
5. Generic headline → doesn't stop the scroll
6. No risk reversal → buyer carries all risk
7. No proof → claims without evidence
8. Too long for low-ticket → buyer loses interest
9. "About me" section too early → nobody cares yet
10. Conditions on guarantee → destroys trust
