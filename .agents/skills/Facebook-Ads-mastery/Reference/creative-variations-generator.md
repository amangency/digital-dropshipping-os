## Hook Templates (First 3 Seconds of Video)

### Pain Hooks:
```
1. "Roz subah [PROBLEM]? Yahi wo ek cheez hai jo sab kuch bigaad rahi hai"
2. "[PROBLEM] se thak gayi ho? Ye ₹[PRICE] ka solution sab badal dega"
3. "Kya aapko bhi [PROBLEM] hota hai? 95% moms ko hota hai"
4. "Stop wasting time on [OLD METHOD]. There's a better way."
5. "[NUMBER]+ [AUDIENCE] ne yahi problem face ki — aur solve bhi ki"
```

### Desire Hooks:
```
1. "Imagine — [DESIRED OUTCOME] in just [TIMEFRAME] 🎯"
2. "What if you could [DESIRED OUTCOME] without [PAIN POINT]?"
3. "[DESIRED OUTCOME] — bina stress, bina tension"
4. "Ye ek choti si cheez aapki [LIFE AREA] completely badal degi"
5. "From [CURRENT STATE] to [DESIRED STATE] — sirf [TIMEFRAME] me"
```

### Fear Hooks:
```
1. "Kya aap ye [NUMBER] galtiyan kar rahe ho? [CONSEQUENCE]"
2. "⚠️ [SCARY STAT/FACT] — aur aap abhi bhi [OLD BEHAVIOR]?"
3. "[AUDIENCE] agar ye nahi kiya to [NEGATIVE OUTCOME]"
4. "Ye one mistake [AUDIENCE] ko sabse zyada paisa waste karati hai"
5. "Your [COMPETITOR/ALTERNATIVE] is already doing this. Are you?"
```

### Proof Hooks:
```
1. "[NUMBER]+ [AUDIENCE] ne already [OUTCOME] achieve kiya ✅"
2. "Maine [TIMEFRAME] me [RESULT] achieve kiya — yahan dekhein kaise"
3. "Real result: ₹[AMOUNT] spend → ₹[AMOUNT] earned 📈"
4. "Before/After: [PERSON] ne [OUTCOME] sirf [TIMEFRAME] me kiya"
5. "[TESTIMONIAL QUOTE] — [NAME], [CITY]"
```

### Status Hooks:
```
1. "Wo [AUDIENCE] jinke [STATUS MARKER] — ye use karti hain"
2. "Top 1% [AUDIENCE] ye ek cheez differently karti hain"
3. "Ye secret sirf successful [AUDIENCE] jaanti hain"
4. "[AUDIENCE] jo [ASPIRATIONAL STATUS] hain — unka ek common formula hai"
5. "Smart [AUDIENCE] ne already switch kar liya. Aap kab karogi?"
```

## Angle Templates (Why Should They Care)

### Pain Angle:
```
Core message: "Your current situation is causing you [SPECIFIC PAIN]"
Best for: People actively suffering from the problem
Example: "Roz subah tiffin banate waqt frustration hota hai na?"
```

### Desire Angle:
```
Core message: "Here's how to achieve [SPECIFIC DESIRED OUTCOME]"
Best for: People who want improvement
Example: "30 din ka tiffin plan, 5 min me ready — poora month tension-free"
```

### Fear Angle:
```
Core message: "If you don't act now, [NEGATIVE CONSEQUENCE]"
Best for: People who are on the fence
Example: "Bacche ka tiffin wapas aata hai? Nutrition ki kami ho rahi hai"
```

### Proof Angle:
```
Core message: "See how others like you achieved [RESULT]"
Best for: Skeptical audience who needs social proof
Example: "500+ Moms ne apne bacche ka tiffin problem solve kiya — dekhein kaise"
```

### Status Angle:
```
Core message: "Join the [ASPIRATIONAL GROUP] who already [DESIRED STATUS]"
Best for: People who want to feel part of something
Example: "Smart Moms ka secret: planned tiffin = happy kids + stress-free mornings"
```

## Format — VIDEO ONLY (Proven for Food/Mom Niche)

### Why Video Only?
```
USER'S PROVEN DATA (23 sales across 3 ad sets):
  Video Ads: 23 sales (100% of all conversions)
  Image Ads: 0 sales (0% — failed in EVERY test)

REASON: Food niche is VISUAL — moms need to SEE the recipes
REASON: Video builds TRUST — face on camera = credibility
REASON: 90-second format covers Hook → Pain → Solution → Proof → CTA
```

### Video Ad Structure (90-Second Framework):

| Timing | Section | Purpose | Duration |
|:---|:---|:---|:---|
| 0-3 sec | **HOOK** | Pattern interrupt — deepest pain or bold claim | 3 sec |
| 3-15 sec | **AGITATE** | Expand the pain, make them feel it | 12 sec |
| 15-35 sec | **REVEAL** | Introduce your solution/mechanism | 20 sec |
| 35-60 sec | **PROOF/BENEFITS** | Show what's inside, results, testimonials | 25 sec |
| 60-75 sec | **OFFER** | Price, bonuses, value stack | 15 sec |
| 75-90 sec | **CTA + URGENCY** | Clear action + limited time | 15 sec |

## Testing Strategy (Updated with Proven Data)

### Week 1 (Day 1-7):
```
Budget: ₹300/day (Ad Set 1 - Interest) + ₹200/day (Ad Set 2 - Broad)
Test: 3 video ads (Pain, Desire, Proof hooks)
Objective: Sales → Purchase
Targeting: Interest-guided (Motherhood, Parenting, Child care)
          + Broad (Engaged Shoppers)

After 48 hrs:
- Check which AD SET wins (Interest vs Broad)
- Check which VIDEO AD wins (Pain vs Desire vs Proof)
- Keep winners, kill losers
```

### Week 2 (Day 8-14):
```
Budget: Increase winner ad set by 20%
Create: 2 new video variations of winning hook (same angle, different script)
Add: Retargeting ad set (₹100/day) for LP visitors who didn't buy
Scale: If ROAS > 2x, continue increasing 20% every 3 days
```

### Week 3+ (Day 15+):
```
Budget: Continue 20% scaling on winners
Create: Lookalike audience from purchasers (if 50+)
Test: New angles (Fear, Status) with video format
Add: Retargeting tiers (video viewers, checkout abandoners)
```

## Kill / Keep / Scale Decision (After 48 Hours)

| Signal | Decision | Action |
|:---|:---|:---|
| Video ad getting clicks but 0 purchases | **KEEP** (give 24 more hours) | Check LP conversion rate |
| Video ad getting purchases at CPP < ₹400 | **SCALE** | +20% budget every 3 days |
| Video ad getting 0 clicks and 0 purchases | **KILL** | Replace with new hook variation |
| Video ad CPP > ₹500 (above product price) | **KEEP** (check bumps/upsells) | If total revenue > spend, scale |
| Ad set performing but one video dragging | **KILL** the bad video | Keep other 2, add new variation |
