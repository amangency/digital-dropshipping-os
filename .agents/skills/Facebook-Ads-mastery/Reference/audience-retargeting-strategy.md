# Audience & Retargeting Strategy Reference

## Audience Temperature → Messaging Matrix

| Temperature | Who | What They Need | Ad Angle | Creative Type |
|:---|:---|:---|:---|:---|
| 🧊 **COLD** | Never seen you | BELIEF | Pain, Desire, Identity | Image ad, Hook-heavy |
| 🔥 **WARM** | Watched/Visited | PROOF | Social proof, Demo | Testimonial, UGC |
| 🔴 **HOT** | Almost bought | URGENCY + Objection removal | Scarcity, FAQ | Discount, Guarantee |

## Custom Audience Sources — Quick Reference

### Website Visitors (Pixel + CAPI)
```
□ All website visitors — last 30/60/90 days
□ Specific page visitors — landing page, checkout, thank you
□ Event-based — ViewContent, AddToCart, InitiateCheckout
□ Time-based — visited in last 7 days vs 30 days
```

### Video Viewers
```
□ 3 seconds watched
□ 10 seconds watched
□ 15 seconds watched
□ 25% watched
□ 50% watched
□ 75% watched ← Good for retargeting
□ 95% watched ← Best for retargeting (high intent)
```

### Instagram/Facebook Engagers
```
□ Visited your profile (last 365 days)
□ Engaged with any post or ad
□ Started following
□ Sent a message
□ Saved any post
```

### Customer Lists
```
□ Buyer list (email + phone) → Exclude from cold campaigns
□ Lead list → Retarget with purchase ads
□ Old prospects → Retarget with new offers
□ High-value customers → Create Lookalike source
```

## Retargeting Map — 5 Levels

```
COLD TRAFFIC (Ads)
    │
    ▼
Level 1: ENGAGED but NOT VISITED
    │   → Saw ad, liked/commented, didn't click
    │   → Retarget: Stronger hook, different angle
    ▼
Level 2: VISITED but NOT OPTED IN/PURCHASED
    │   → Came to LP, left without action
    │   → Retarget: Proof, testimonials, urgency
    ▼
Level 3: OPTED IN but NOT ATTENDED (webinar funnels)
    │   → Registered but didn't show up
    │   → Retarget: Replay link, FOMO, social proof
    ▼
Level 4: ATTENDED/ENGAGED but NOT BOUGHT
    │   → Consumed content, didn't purchase
    │   → Retarget: Objection removal, guarantee, discount
    ▼
Level 5: BOUGHT (Existing Customers)
        → Purchased front-end
        → Retarget: Backend products, upsells, new offers
```

## Lookalike Audience Guide

### Percentage Guide:
```
1% → Exact match (ALWAYS START HERE)
2% → Mostly similar
3% → Somewhat similar  
4% → Broadly similar
5% → Widest match (least similar)
```

### Best Source Audiences for Lookalike:
```
Rank 1: Purchasers (highest quality signal)
Rank 2: High-value purchasers (bought upsell too)
Rank 3: Leads (opted in / registered)
Rank 4: Website visitors (broad but relevant)
Rank 5: Video 75%+ viewers (high engagement)
```

### Minimum Source Size: 1000+ people
### Location: India (or specific states if needed)
### Update Frequency: Lookalike auto-updates as source grows

## When to Use Which Audience Type

| Situation | Audience Type | Why |
|:---|:---|:---|
| Brand new account, no data | Broad + Advantage+ | Let Meta discover |
| First week of ads | Broad (age/gender/location only) | Simple, let creative do targeting |
| After 50 purchases | Lookalike 1% from purchasers | Scale to similar people |
| Retargeting LP visitors | Custom (website 30 days) | Warm audience, higher CVR |
| Retargeting video viewers | Custom (75%+ viewers) | High engagement signal |
| Selling to existing buyers | Custom (customer list) | Backend product push |
| Free lead magnet | Manual targeting | Control audience quality |
| Paid product (₹199+) | Advantage+ Audience | Meta's AI finds buyers |
